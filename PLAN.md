# Plan: Axon Voice v1
_Locked via grill-with-docs — by Claude + Theo. Terms per CONTEXT.md._

## Goal
Ship a local-first voice dictation desktop app for Windows that runs at login, costs nothing, and keeps audio on-device. The user activates a Mode (Hold-to-Talk or Hands-Free), speaks, and the resulting Transcript is inserted at the cursor (paste-first, type fallback) and left on the clipboard. A tray-opened Main Window exposes session History, Snippets, and Settings. Mac is a later port: the PyQt6 UI carries over, but global hotkeys, login startup, GPU detection, tray, and keyboard/clipboard injection are platform-specific seams that get re-adapted — a UI repackage plus per-platform adapters, not a clean repackage and not a full rewrite.

## Approach
0. **Reconcile the existing scaffold** — `src/` already exists from an earlier session and predates the decisions below. Before building new features, bring the scaffold into line: `transcriber.py` (float16→int8_float16, 10GB→VRAM-tier thresholds, CPU clamp), `output.py` (clipboard restore→leave Transcript copied; `keyboard`→`pynput`), `processing.py` (pipeline order), `app.py` (job state machine), `window.py`/`hotkeys.py` (real rebinding). This is step 0 because the plan and code currently disagree.
1. **Transcription core** — `faster-whisper` (CTranslate2 backend) with `compute_type="int8_float16"` on CUDA. Auto-Detect reads **total** VRAM via `pynvml`/NVML — *not* torch, which faster-whisper doesn't need for inference and which would bloat the build by hundreds of MB for one VRAM read — and picks the largest Model that fits with headroom: `large-v3` ≥6GB total, `medium` ≥4GB, `small` ≥2GB, else `base`. CPU fallback resolves to `min(requested, small)` with a warning toast. Model loads on a background worker; UI shows a clear "loading"/"ready" state and stays usable before ready.
2. **First-Run Download** — fetch the resolved Model on first run, **pinning the HuggingFace repo revision and verifying expected file hashes** before load (no float-by-name fetch — prevents silent model substitution). Detect whether weights are already cached; if not, show an explicit download-progress UI with an offline-error state (not faster-whisper's silent implicit download behind a `print`). Cache for later Sessions.
3. **Global hotkeys** — `Ctrl+Space` = Hold-to-Talk (record on keydown, stop+transcribe on keyup). `Ctrl+Win+Space` = Hands-Free toggle (press to start, same combo to stop). Implemented via `pynput` (standardized with Output to avoid the `keyboard` package's Windows-admin requirement). Both rebindable end-to-end in Settings (kept in v1 by explicit request). Rebinding **validates** the chosen combo: reject reserved OS shortcuts, duplicate bindings, and untypeable combinations, and run a registration/listen test before saving with a fallback workflow on failure. The `Win`-key combo may be swallowed by the OS shell — `Ctrl+Alt+Space` is the named non-Win fallback for Hands-Free, auto-selected if the `Win` combo fails its registration test.
4. **Audio capture** — `sounddevice` mono @ 16kHz buffered for the active Mode's duration. **Hands-Free enforces a max recording duration** (auto-stop with user feedback) so a forgotten session can't exhaust memory or produce an unusably slow transcription.
5. **Processing pipeline** — fixed order: Whisper → Filler Cleanup → Snippet expansion → Output. **Filler Cleanup** defaults off and is conservative: strip standalone `um`/`uh` globally, but `like`/`you know` only in interjection position (bounded by sentence start/pauses/commas), never inside legitimate phrases. **Snippet expansion** sorts keywords by descending length (so `api key` wins over `api`) and the Snippets UI validates for collisions; deterministic, no second model.
6. **Output** — **paste-first**: set the clipboard to the Transcript, then send the paste shortcut (`Ctrl+V` via `pynput`). Paste handles Unicode, newlines, and symbols natively where per-character synthetic typing fails or misorders. A type-fallback covers apps that block paste. Either way the Transcript is left on the clipboard (per CONTEXT); prior contents are intentionally not restored, and clipboard remains the safety net.
7. **Overlay** — frameless PyQt6 pill, bottom-center, animated waveform bars + `HOLD`/`FREE` label; appears on Mode activation, vanishes after Output.
8. **Tray Icon** — `QSystemTrayIcon`, keeps the app alive (`setQuitOnLastWindowClosed(False)`), click opens the Main Window. Tray + window surface recoverable-error toasts (see step 12).
9. **Main Window** — VoxDrop-style sidebar (History, Snippets, Settings), basic light liquid-glass aesthetic for v1. History = session-only Activity Log, timestamped, Copy button per entry. Snippets = CRUD over the keyword→text store with collision validation. Settings = hotkey rebind, Filler Cleanup toggle, Model override, login-startup toggle. **Model override is validated against detected hardware**: selecting a Model too large for available VRAM prompts for confirmation before downgrading/CPU-falling-back, rather than silently ignoring the explicit choice.
10. **Login startup** — register under `HKCU\…\CurrentVersion\Run` with a properly quoted executable path; toggleable in Settings with a clean removal flow and error reporting.
11. **Single instance** — a single-instance lock ensures relaunch (or login autostart firing twice) focuses the existing tray app instead of starting a second process that would race on hotkeys and config.
12. **Concurrency / job state** — a single transcription worker queue serializes all `WhisperModel.transcribe()` calls (faster-whisper thread-safety is not assumed). Overlapping Dictations are queued or explicitly rejected with user feedback, never silently dropped.
13. **Observability** — structured logging to a rotating file in `%APPDATA%` for audio/hotkey/model-load/clipboard/output failures, plus user-visible tray/window toasts for recoverable errors. **Transcript and audio contents are banned from logs by default**; a separate opt-in redacted-diagnostic mode is the only way they appear. No silent `print`-only failure paths.
14. **Config & data safety** — Snippet and config JSON in `%APPDATA%` are schema-validated, written atomically (temp + rename) under a file lock, and corrupt files are backed up before reset (not silently wiped). Document that Snippets may hold sensitive expansions and never leave the machine.
15. **Packaging** — PyInstaller single `.exe`, GitHub Releases. Build size is **not** ~50MB: realistic targets are roughly **CPU-only ~120–200MB**, **CUDA-detected (DLLs not bundled, relies on a present CUDA runtime) ~150–250MB**, and **CUDA-bundled (cuDNN/cuBLAS shipped) ~1–2GB+**. Final target measured during packaging, not promised up front. Model weights are never bundled (see First-Run Download).

## Key decisions & tradeoffs
- **All-Python + PyQt6, no Electron** — one language, single-`.exe` packaging. The **UI** is portable to Mac; system integration (global hotkeys, login startup, CUDA, tray behavior, keyboard injection) needs per-platform adapters — the Mac port is a re-adaptation of those seams, not a UI rewrite. See [ADR 0001](docs/adr/0001-all-python-stack.md).
- **Local faster-whisper, `int8_float16`, no cloud** — quantization lets `large-v3` fit the dev machine's 8.6GB 4070 (RTX 4070 Laptop, *not* a 4090 — corrected 2026-06-05). Auto-Detect keys off total VRAM with headroom. CPU clamped to `small`. Model downloaded on first run, not bundled. See [ADR 0002](docs/adr/0002-local-whisper-no-api.md).
- **`pynput` for both hotkeys and output, paste-first** — avoids the `keyboard` package's elevated-privilege requirement; paste (`Ctrl+V`) over per-char typing handles Unicode/newlines reliably, with a type-fallback.
- **Drop torch; detect VRAM via `pynvml`** — faster-whisper's CTranslate2 backend doesn't use torch for inference. Torch existed in the scaffold only to read VRAM; replacing it with `pynvml` removes a multi-hundred-MB dependency from the bundle. (`requirements.txt` updated in step 0.)
- **Pinned model revision + hash verification** — the model is fetched at runtime, so supply-chain integrity (pinned HF revision, verified hashes) replaces the trust you'd get from bundling.
- **Single serialized transcription worker** — trades parallelism (irrelevant for one user) for correctness against unknown model thread-safety and dropped-job bugs.
- **Filler Cleanup default off, conservative** — naive global `like` stripping damages real text; off-by-default protects correctness until the interjection heuristics are validated.
- **Session-only History** — no cross-Session persistence by design; simple privacy story, trivial storage.

## Risks / open questions
- `Ctrl+Win+Space` may be intercepted by the Windows shell before `pynput` sees it; the registration test detects this and auto-selects the `Ctrl+Alt+Space` fallback (step 3).
- `int8_float16` accuracy delta vs float16 on technical/architecture vocabulary is unmeasured — acceptable until proven otherwise; revisit if proper nouns degrade.
- Auto-type via synthetic keystrokes can misfire in apps with IME or fast focus changes; clipboard copy is the safety net.
- Interjection-only filler heuristics are inherently imperfect; some fillers will survive or some edges mis-strip. Default-off limits blast radius.
- PyInstaller + CUDA/cuDNN DLLs are fiddly to bundle; first-run model download helps but the CUDA runtime must still ship or be detected, with a graceful CPU-clamp path when absent. Final `.exe` size depends on this choice (see step 15) and is measured, not promised.
- HuggingFace availability/outage blocks First-Run Download; pinned-revision fetch needs a clear retry/offline-error path.

## Out of scope (v1)
- Mac build (later port)
- Voice commands / phrase-triggered keyboard actions
- LLM grammar polishing (only conservative regex Filler Cleanup)
- Persistent cross-session History
- Cloud sync, accounts, multi-language UI
